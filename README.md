# 广西河池政协网（hechi-zhengxie）

> 河池市融媒体中心承建并负责技术维护的政务门户网站源码仓库。
> 主办：中国人民政治协商会议河池市委员会办公室；官网：www.gxhczx.gov.cn

## 目标架构（规划，源自《河池政协网开发思路与技术栈方案》）

| 层 | 选型 |
| --- | --- |
