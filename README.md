# 广西河池政协网（hechi-zhengxie）

河池市融媒体中心承建并负责技术维护的政务门户网站源码仓库。

## 项目定位

内容型政务门户（信息公开、政策解读、互动交流），无办事服务系统。主站采用 PHP 轻量 CMS，按“全国政协网形态”落地：**全文静态化 + 响应式（PC/移动）+ 无障碍/适老化 + 等保二级 + 多站点预留**。

业务与技术主线（参照《河池政协网开发思路与技术栈方案》）：

- 主站：PHP 8.x 轻量 CMS，首页/栏目/详情页全文静态化生成，Nginx 直出，降动态请求、防注入面最小。
- 前后台分离：**内容/资源 REST API** 为数据出口，前台（PHP SSR）、后台管理、校对 Python 服务统一经 API 对接，便于多端复用与日后换代。
- 多站点预留：以 `site_id` 维度预留县区子站（罗城/环江/南丹/天峨/都安/大化及后续未建站县区），本期只建主站。
- 智能编校模块：本期独立 Python 微服务（本地词库 + 厂商校对 API + AI 兜底），与主站以接口契约先行、并行开发。

## 技术栈

| 层 | 选型 |
| --- | --- |
| 云资源 | 移动云（本期） |
| Web | Nginx（virtualhost 多站点） |
| 后端 | PHP 8.x（应用层 CMS，兼容旧站迁移） |
| 数据库 | MySQL 8 |
| 缓存 | Redis |
| 前端 | 服务端渲染静态 HTML + 响应式 CSS + 原生 JS/轻量库 |
| 内容/资源 API | REST（JSON） |
| 无障碍/适老 | govwza.cn 组件或开发等价方案 |
| 编校微服务 | Python 服务 + 厂商 API + 本地词库 |
| 数据迁移 | 旧库导出、清洗去重、图片附件迁移、301 URL 映射 |
| 安全 | WAF/安全组、等保二级、日志 180 天、三级备份、敏感词过滤 |

## 目录结构

```
hechi-zhengxie/
├── docs/                  # 需求、方案、接口契约、运维文档
├── backend/               # 河池政协网主站（PHP CMS：应用层 + 前端 SSR + 静态化发布）
│   ├── public/            # Web 根目录（Nginx 指向 / 入口）
│   ├── src/               # PHP 源码
│   ├── config/            # 配置
│   ├── routes/            # 路由
│   ├── templates/         # 前端模板（SSR 渲染）
│   └── resources/         # 静态资源（css/js/img）
├── api/                   # 内容/资源 REST API（前台/后台/校对/多端共用）
├── services/
│   └── proofreader/       # 智能编校微服务（独立 Python 服务）
│       ├── app/           # 服务源码
│       ├── data/          # 本地词库
│       └── tests/
├── database/
│   ├── migrations/        # MySQL 表结构变更
│   └── seed/              # 基础数据
├── tools/
│   └── migrate/           # 旧站数据迁移（导出/清洗/301 映射）
└── tests/                 # 跨模块集成测试
```

## 一期范围与时间约束

- 本期只建**政协主站 + 校对模块**，县区子站与稿件互通缓做，按预留接口后续开通。
- 政务云 **2026-11-01** 停服前完成迁出；主站对照 61 天窗口（9/1—11/1）推进。
- 数据策略：近 3 年数据公开访问，更早数据后台留存不公开；旧 URL 统一 301 映射保 SEO 与外链。
