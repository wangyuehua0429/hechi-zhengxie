# 河池政协网 · 后台界面可访问性说明

> 编制日期：2026 年 9 月 11 日
> 适用范围：内容管理后台（`/admin`），本轮先做登录页与全站通用样式。
> 依据：`ui-ux-pro-max` 技能的 ux 规则库检索结果（2026-09-11），配色与字号沿用本站既有政务红，不采用技能库给的通用藏青蓝。

## 1. 本轮改了什么

### 1.1 先说一个原有缺陷：登录页被套在后台外壳里

登录页模板自己就是一份完整的 HTML 文档，但渲染时又被塞进了后台布局（顶栏 + 侧栏）里，形成嵌套 document。浏览器遇到嵌套 `<body>` 会把属性合并到外层 body 上，所以页面看起来“勉强能用”，实际上侧栏的“概览”“接口状态”和顶栏站点名会一起出现在未登录的登录页上。

处理方式：`HechiZx\Admin\View` 增加 `bare()`，登录页改走不带外壳的渲染路径。现在登录页输出的是干净的独立文档。

### 1.2 对比度实测与修正

下表是改动前后按 WCAG 相对亮度公式算出的对比度（本轮实测计算，非估算）：

| 用途 | 改前 | 改后 | 说明 |
| --- | --- | --- | --- |
| 次要文字 `--muted` | `#777` 在白底 4.48:1 | `#5f6771` 在白底 5.73:1 | 改前差 0.02 不到 AA 要求的 4.5:1 |
| 表单控件描边 | `#cfd4da` 在白底 1.49:1 | `#8a9199` 在白底 3.19:1 | 满足非文本对比度 3:1，输入框边界才看得出来 |

### 1.3 交互与焦点

1. **可见焦点**：全站 `:focus-visible` 统一 3px 品牌红描边，偏移 1px；没有用 `outline: none` 抹掉焦点。
2. **触控目标**：`.btn`／`.btn-primary` 最小高度 44px，登录按钮 48px。
3. **状态过渡**：按钮与输入框的边框、背景、文字色加 150ms 过渡；同时用 `prefers-reduced-motion` 在系统要求减少动效时关闭过渡。
4. **登录失败的错误摘要**：`role="alert"` + `tabindex="-1"`，失败后焦点落在摘要上，键盘与读屏用户不必自己找错误在哪里；摘要本身是非交互容器，用的是与自身红色调一致的浅焦点环。
5. **不做的事**：不拦截粘贴、不屏蔽密码管理器（`autocomplete="username"`／`current-password` 保留），符合 WCAG 2.2 的“可访问的认证”要求。
6. **长页面回到顶部**：后台外壳里固定一个位于页面左下角的“↑ 回到顶部”，滚过 400px 才出现、回到顶部自动隐藏；按钮高 44px 满足触控下限，用 `button` 元素，可被 Tab 聚焦、回车触发。系统开启“减少动效”时直接跳转，不做平滑滚动。模板里默认 `hidden`，没有脚本时不会留下一个点不动的按钮。

### 1.4 登录页具体改动

1. 品牌区改为“政协”标识块 + 站点名 + “内容管理后台”。
2. 新增密码可见性开关：有可访问名称（`aria-label`）与状态（`aria-pressed`），默认 `hidden`，由脚本启用，禁用脚本时不显示。
3. 登录按钮提交后进入“登录中…”并禁用，防止重复提交。
4. 增加一行说明：忘记密码联系管理员重置，系统仅限授权人员使用，操作记入日志。
5. `<meta name="color-scheme" content="light">` 与 `noindex`。

### 1.5 实测发现的第二个问题：SVG 上的 hidden 不生效

密码图标最初用 `hidden` 属性控制显隐，实测 `getComputedStyle` 返回 `display: block`——UA 样式表里的 `[hidden] { display: none }` 不作用于 SVG 元素，导致眼睛与斜杠两个图标同时显示。改成用 CSS 类控制显隐。

## 3. 尚未处理

- 稿件管理与栏目管理界面已在 2026-09-11 做过一轮结构与交互重构（见 [后台稿件与栏目管理重构说明](后台稿件与栏目管理重构说明（2026-09-11）.md)）。本轮在这两个模块补的可访问性项：跳过导航链接、面包屑、勾选框逐行 `aria-label`、全选半选状态、提示条按类型给 `role="status"`／`role="alert"`、正文预览 iframe 带 `title` 与 `sandbox`、状态影响的前端行为都用 `aria-expanded`／`aria-current` 表达。
- 2026-09-12 增量：正文换成富文本编辑器后，编辑区由 SunEditor 的 `contenteditable` 承载，原 textarea 保留为脚本不可用时的降级通道；站内横幅的图片框新增“选后即时预览”，预览图与“待上传的预览 · 点保存后生效”提示条都在原预览框内，随提交或刷新消失。**未专门复测**：键盘用户经编辑器工具栏的完整走查、读屏软件对 `contenteditable` 与工具栏的实际播报。
- 用户与角色、操作日志两页仍只统一了焦点、对比度与触控尺寸，未做布局改版。
- 登录页未做“大写锁定提示”“验证码”“双因素”，是否需要按等保要求补，待确认。
- 未做深色模式；政务后台一般用浅色，暂不引入。
