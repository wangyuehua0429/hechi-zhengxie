# 栏目新建与删除（2026-09-12）

> 改动范围：`/admin/channel/new`（新建）、`/admin/channel/{栏目号}/delete`（删除确认页）、`/admin/channels`（列表入口）、`/admin/channel/{栏目号}`（编辑页入口）。
> 起因：后台此前只能改已有栏目，43 个栏目全部来自旧站快照，编辑要新增一个栏目或清掉一个废栏目都没有入口（README 与 backend/README 均把“栏目新建与删除”列为尚未做）。

## 一、新建栏目

入口在栏目管理列表右上角的“新建栏目”。表单分四块：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 挂在哪个一级栏目下 | — | 留空＝新建一个一级栏目；选了某个一级栏目＝作为它的子栏目。系统只做两级，选到子栏目会被挡下 |
| 栏目号 | 是 | 1—32 位字母、数字、下划线或连字符，全站唯一；`new`／`create`／`index`／`delete` 是后台保留字，不能占用 |
| URL 标识 | 否 | 静态页目录名；留空用栏目号。同名标识不会覆盖别人——发布器会补栏目号（见 [旧地址301映射说明.md](旧地址301映射说明.md) 第三节） |
| 一级栏目名 / 子栏目名 | 子栏目名必填 | 挂在已有分组下时，一级栏目名自动沿用父栏目，避免同一组出现两个一级名（前台导航条按一级名分组） |
| 版式 / 状态 | — | 版式六类＋领导＋一页式共八种；可以建成“已下线”，等内容备好再上线 |
| 栏目简介 | 否 | 前台栏目页顶部展示 |

新建后的位置：挂在某组下时排在该组最后，新建一级栏目时排在整站导航最后；之后都可在列表里上移／下移。栏目号与 URL 标识建好后不可改——前台链接与旧地址 301 都按它们走。

## 二、删除栏目

入口在栏目编辑页右上角的“删除栏目”，进入的是确认页（不是点一下就删）。四类关联会挡下删除，并在页面上逐条说明怎么改：

1. **还有稿件挂在这个栏目**（含草稿与回收站稿件）；
2. **下面还有子栏目**；
3. **首页“其他栏目”的某个模块绑定了它**（单个栏目、标签分组、一级栏目含子栏目三种绑定都会查）；
4. **首页顶部导航的某个入口指向它**。

确认删除时会清理只跟着这个栏目走的附属记录：角色里勾选的栏目数据范围（`sys_role_channel`）、该栏目的旧地址 301 映射（`sys_url_redirect` 里 `/news_list.php?id=<栏目号>` 等三条）。稿件与上传文件不受影响（本来就不允许带着稿件删）。

删除只改库；前台栏目页与 sitemap 要等下一次发布才更新，确认页上写明了这一点。

## 三、顺带修掉的一处显示问题

一级栏目的 `parent_type` 在 seed 里写的是**自身栏目号**（旧库 `rd_menu.ID` 的写法），此前编辑页把“自己”当成了上级栏目，标题会显示成“市政协动态 › 市政协动态”。现在统一按“`parent_type` 为空或等于自身栏目号即一级栏目”判断（`ChannelRepository::isTopLevel()`），编辑页与删除页只在真有上级时才显示层级。
