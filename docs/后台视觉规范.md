# 河池政协网 · 后台视觉规范

> 编制日期：2026 年 9 月 11 日
> 适用范围：内容管理后台（`/admin`）。首页管理四页（导航栏目／头条轮换／其他栏目／站内横幅）本轮未逐一改造，但应当按本文的令牌与组件写法对齐。
> 依据：`ui-ux-pro-max` 技能的 “Accessible & Ethical” 风格规则与 dense（8/10）密度取向；技能库给出的藏青蓝配色与 Atkinson Hyperlegible 字体未采纳（与政务红品牌、中文字体栈不适配），只取可访问性与密度规则。

## 1. 设计令牌

全部定义在 `backend/public/assets/admin.css` 的 `:root`，新写的样式从令牌取值，避免再出现一次性数字。

| 类别 | 令牌 | 值 | 说明 |
| --- | --- | --- | --- |
| 品牌 | `--brand` | `#a51d22` | 与站点前台 `--primary` 同值，从后台点开前台不再有色差 |
| 品牌 | `--brand-dark` | `#7f1418` | 悬停、按下 |
| 品牌 | `--brand-soft` | `#faeeee` | 浅底高亮（chip 悬停、子栏目分隔线） |
| 文字 | `--ink` / `--muted` | `#222` / `#5f6771` | `--muted` 在白底 5.73:1，满足 AA |
| 描边 | `--line` / `--field-line` | `#e3e6ea` / `#8a9199` | 表单控件描边 3.19:1，满足非文本对比度 3:1 |
| 间距 | `--space-1..6` | 4／8／12／16／24／32 | 卡片、面板、表单优先用这组 |
| 圆角 | `--radius-sm` / `--radius` / `--radius-lg` | 4／6／10 | 控件／卡片／登录卡 |
| 字号 | `--text-xs..xl` | 12／13／15／17／22 | 正文 15px，次要信息不低于 13px |
| 阴影 | `--shadow-card` / `--shadow-float` | — | 卡片／吸底工具条 |

对比度实测（改动后按 WCAG 相对亮度公式计算）：白字在 `#a51d22` 上 7.5:1、在 `#7f1418` 上 10.42:1；`#a51d22` 在 `#faeeee` 上 6.62:1。

## 2. 红色语义

红色只表达三种意思：**品牌标识**（顶栏标识块、主按钮）、**危险操作**（删除、撤回、红叉）、**需要处理**。概览页统计卡因此只有“稿件总数”标红，其余数字用 `--ink`，值为 0 的用 `--muted` 并降字重；八张卡全标红时红色就不再表示重点。

## 3. 栏目导航条（两级）

栏目共 43 个，其中 25 个一级项、5 个含子栏目。规则：

- 默认只渲染“全部栏目 + 25 个一级项”（约 2 行），不铺开 43 个 chip。
- 选中项落在某个多子栏目组里时，该组展开显示子 chip；形态仍是导航条，不做下拉。
- **母栏目是开关**：点一次 = 按整组筛选并展开子栏目（母栏目实心红、子栏目浅红底）；已经是整组筛选状态时再点一次 = 收起子栏目、回到“全部栏目”。展开中但未被选中的母栏目用浅红底，与自己的子栏目连成一组。
- **一级项与子栏目分开传参**：一级项走 `?group=<一级栏目号>`，子项走 `?channel=<栏目号>`。原因是“栏目号 401 既是‘政协会议’这一组的组号，又是组内‘全体会议’的号”，只看栏目号无法区分用户想筛整组还是某一个。
- 一级项上的数字是该组各子栏目之和；数字口径与当前列表筛选（稿库 + 关键词）一致。

## 4. 组件约定

| 组件 | 类名 | 约定 |
| --- | --- | --- |
| 状态标签 | `.tag` + `.tag-<状态>` | 胶囊形（`999px`），最小宽度 3.4em，12px |
| 计数标签 | `.vault-num` / `.chip-num` | 小方角 + 描边，与状态标签在形状上区分 |
| 稿库导航 | `.vault-nav` / `.vault-chip` | 胶囊 chip，选中实心品牌色 |
| 栏目导航 | `.channel-nav` / `.channel-chip` / `.channel-chip--group` / `.channel-chip--child` | 一级项加粗并带小三角，子项 13px 且左侧有浅色分隔线 |
| 表格 | `.grid` | 行悬停浅底 `#fafbfc`，空结果行不随鼠标变色 |
| 空状态 | `.empty-icon` / `.empty-title` / `.empty-hint` / `.empty-action` | 图标 + 说明 + 主行动按钮 |
| 提示条 | `.flash` + `.flash-icon` | 左侧色条 + 图标，`role="status"`／`role="alert"` |
| 提交中 | `.btn.is-busy` | 改文案为“处理中…”并压暗，**不使用 `disabled`** |

## 5. 两个必须遵守的坑

1. **提交中的按钮不能 `disabled`。** 新建稿件的“保存并发布／保存为草稿”与稿库流转按钮都靠 `name/value` 传参，按钮被禁用后参数不会提交，服务端就收不到 `status`／`action`。统一改用 `aria-busy` + `.is-busy` + `pointer-events:none`。
2. **图标一律内联 SVG。** 项目无 `composer.json`、无 npm 依赖，内网部署也不能依赖外部图标 CDN；统一放在 `backend/templates/admin/_icons.php`，用 `require` 取数组（不是定义函数，避免同请求内重复声明）。

- 后台表格没有真正的数字列，因此未做“数字右对齐”；ID 在次要行里展示。
